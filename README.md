# Geothermal Energy Potential Calculator 🌋⚡

A lightweight Python-based engineering tool designed to estimate the thermal power output of a geothermal power plant using fluid flow rate and temperature differentials.

## 📌 Features
- Calculates the mass flow thermal energy conversion.
- Uses standard specific heat capacity of water.
- Simple, efficient, and command-line friendly.

## 🚀 How to Run
1. Make sure you have Python installed.
2. Run the script in your terminal:
```bash
python geothermal_calculator.py
